# Paragon Apartment Management System (PAMS)
Advanced Software Development – UFCF8S-30-2  
Group Project – 2025/26

## Project Overview

PAMS is a desktop-based apartment management system that is designed to support multiple location property operations across the UK.

The system addresses:

- Role-based access control
- Tenant management
- Apartment management
- Payment & billing
- Maintenance tracking
- Operational reporting
- Security and data validation

This project follows an Agile development approach and includes UML-driven design, implementation, and testing.
